# Release v0.9.1

**Date:** 2026-05-24
**Track:** T9.2 — Multi-provider Model Convention

---

## Summary

This release separates provider from model in all agent frontmatter. Previously, `model: sonnet` implicitly meant "Claude Sonnet (latest)." Starting with v0.9.1, agent files carry an explicit `provider: claude` line directly above the existing `model:` line, making the cloud provider unambiguous and enabling Agent OS to target Claude, Gemini, and future providers without frontmatter collisions.

The change is purely additive — no model tiers were altered. All 13 canonical agents default to `provider: claude`. The `install-agent-scaffold` skill now emits the two-field shape for every newly created agent.

## Compatibility Window

This change is covered by the **2-sprint minimum compatibility window** established in AGENTIC.md §9.2.

- **Window active through:** Sprint 9, Sprint 10, and Sprint 11 (minimum).
- **`provider:` absent defaults to `claude`.** Installed agent files that do not yet have the `provider:` field continue to work without modification during this window.
- After the window closes (Sprint 11 at the earliest), installed agents missing `provider:` will receive a warning nudge when `/refresh-agent-os` is run — not a hard break.

No Agent OS tooling requires `provider:` to be present. The field is read when present; its absence is not an error.

---

## User Action Required

Run `/refresh-agent-os` to apply the updated agent files to your install at `~/.claude/agents/`. No action is required immediately — your existing installed agents continue to work without `provider:` during the compatibility window. Running the refresh will bring your install up to date with the canonical shape.
