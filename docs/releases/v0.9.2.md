# Release v0.9.2

## 1. Version

`v0.9.2`

## 2. Date

`2026-05-24`

## 3. Summary

This patch release closes three correctness bugs surfaced during post-T9.1 stress-testing of `/refresh-agent-os` and `skills-manifest.json`, and codifies the two protocol gaps that allowed them through Bridge review. Fix 1 adds silent absent-directory handling to Phase 2 of `/refresh-agent-os`: if `~/.claude/skills/` or `~/.claude/agents/` does not exist on a fresh install, the skill now creates it silently and proceeds with an empty installed set. Fix 2 removes `open-sprint` from the `skills-manifest.json` `skills` array, correcting a cross-array invariant violation where the name appeared in both `skills` (prescriptive) and `renames[].from` (deprecated). Fix 3 integrates CLAUDE.md reference scanning into the Phase 3/4/5 flow: when a diff contains at least one rename or removal, the skill now scans the project's `CLAUDE.md` for stale skill references, surfaces them as `[claude.md]` rows in the Phase 4 action table alongside skill and agent changes, and applies approved edits in Phase 5 — all in a single user-approval pass. Two protocol additions accompany the fixes: AGENTIC.md §9.7 codifies the absent-path precondition (§9.7.1) and cross-array mutual exclusion (§9.7.2) as binding Bridge verification requirements, and `claude/agents/architect.md` gains a fifth Bridge Self-Check gate ("Canonical-Change Verification Gate") cross-referencing §9.7.

## 4. Changed Files

- `claude/skills/refresh-agent-os/SKILL.md` — Fix 1 (Phase 2 absent-directory handling), Fix 3 (Phase 3/4/5 CLAUDE.md reference scan integration)
