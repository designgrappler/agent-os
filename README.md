### Usage
1.  **Environment Setup**: Install the Gemini CLI and initialize your **Policy Hub** in `~/.gemini/policies/conductor_enforcement.toml`.
2.  **Skill Deployment**: Use the **Deploy Protocol** for any skill:
    ```bash
    # Example: Deploy the Conductor Bundle
    gemini skills install https://github.com/designgrappler/agent-skills --path skills/conductor-bundle
    ```
3.  **Automated Handoff**: Follow the Architect's generated shell commands to "Wake" specialists in fresh, isolated sessions.
